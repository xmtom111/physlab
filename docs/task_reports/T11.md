DEVIATIONS:
- There was no scene-file loader. T11 adds `configs/scenes/*.yaml` and a loader that builds the existing `SceneSpec`. `table_gantry` starts with no Menagerie checkout. `table_arm` is the xArm scene the example assembles on.
- The sim mock printer uses a clock that jumps forward, so a print job reaches `DONE` on the first status read. The tool still returns a job id and the part is spawned into the world.
- `configure_logging` gained a keyword-only `stream` argument, defaulting to stdout. The MCP server passes stderr. Existing callers are unchanged.
- `PHYSLAB_SCENE` cannot select the scene. `load_config` would treat it as a config field and reject it. The selector is `MCP_SCENE`.
- Procedural gantry Y and Z position servos overshoot and the joint move times out. An X-only target settles. The test uses that target. The arm scene is the one used for gripping.
- Token verification against the approved file is not implemented. `gate` only requires a non-empty token in real mode.
- `uv sync --all-extras --dev` was not re-run. T1–T10 already recorded that it fails because pyaudio needs portaudio.h.
