VERIFIED APIS:
- opencv-contrib-python-headless, imported as cv2 5.0.0. Inspected from the installed package.
- cv2.aruco.DICT_4X4_50 is int 0. getPredefinedDictionary(code) returns a Dictionary whose bytesList.shape is (50, 2, 4), so ids are 0 through 49.
- cv2.aruco.generateImageMarker(dictionary, id, sidePixels[, img[, borderBits]]) -> img. Used to write the cached PNG.
- cv2.aruco.ArucoDetector(dictionary, DetectorParameters()). detectMarkers(image) -> corners, ids, rejectedImgPoints. Corners are 4 points clockwise from the marker top-left. ids is None when nothing is found.
- cv2.aruco.DetectorParameters.cornerRefinementMethod. CORNER_REFINE_NONE is 0, CORNER_REFINE_SUBPIX is 1, CORNER_REFINE_CONTOUR is 2, CORNER_REFINE_APRILTAG is 3. Detection uses APRILTAG. Without it, one of the 10 seeded yaws was missed; with it, all 10 views were found and the fused rotation stayed under 0.2 deg in a probe.
- cv2.SOLVEPNP_IPPE_SQUARE is 5. cv2.solvePnPGeneric(objectPoints, imagePoints, cameraMatrix, distCoeffs, flags=SOLVEPNP_IPPE_SQUARE) -> ok, rvecs, tvecs, errors. Two solutions. Object points that match the corner order and recover a pose in front of the camera are (-s/2, +s/2, 0), (+s/2, +s/2, 0), (+s/2, -s/2, 0), (-s/2, -s/2, 0). The opposite Y order put the marker at z ≈ 0.
- On a perfect fronto-parallel square, OpenCV 5's IPPE_SQUARE pair can omit the true pose and report a ~15 deg tilted pose as the lower error. cv2.solvePnPRefineLM(objectPoints, imagePoints, cameraMatrix, distCoeffs, rvec, tvec[, criteria]) -> rvec, tvec, started from each IPPE solution, returns the true pose (synthetic error ~0). The code keeps the refined pose with positive z and the smaller reprojection error.
- MuJoCo camera frame from cam_xpos/cam_xmat is X right, Y up, Z backward. OpenCV is X right, Y down, Z forward. The conversion used in Localizer is 180 deg about X, quaternion (0, 1, 0, 0), then Pose.compose with the camera's pose_in_world.
- MjSpec.add_texture(name, type=mjTEXTURE_2D, file=path). add_material(textures=["", name]) places the texture in the RGB role. textures=["name"] alone lands in the USER role and the classic renderer draws a blank face. Geom rgba must be white or it tints the marker. emission=1, specular=0, shininess=0 keep the print high contrast. A white quiet zone (20% of the marker side on each edge) is required for detection on a dark object; plate_scale maps that padded image back so the black square is aruco_size_m wide.
