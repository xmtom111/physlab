KNOWN LIMITATIONS:
- `uv sync --all-extras` does not install here. `hello-robot-stretch-body` pulls `pyaudio`, which needs a system `portaudio` development package, and the Stretch stack also pulls native pieces such as `spidev`. The real extra is declared and locked, not installed.
- `load_config()` finds `configs/default.yaml` by walking up from the working directory, then the `src` checkout. A non-editable install launched outside the repo needs an explicit path. Relative path fields resolve against the parent of the `configs/` directory.
- structlog configuration is process-global. `configure_logging` is the only writer. There is no other global mutable state.
- Unseeded run ids use `secrets.token_hex` so two runs in the same second do not collide. Pass `seed` when the hex suffix must be reproducible.
- `Registry.create` annotates `**kwargs` as `Any` because registered factories do not share one signature. Event `params` and `result` are `dict[str, Any]` because they are open JSON objects.
- `DependencyMissing` and the other unused error subclasses are defined for later tasks and are not raised yet. Later packages are docstrings only. `scripts/fetch_assets.py` raises `NotImplementedError("Implemented in T2")`.
- `sim.gl_backend` is stored only. Rendering is not implemented. Headless use is `MUJOCO_GL=egl`, falling back to `osmesa`, documented in the README.
- Scaffold YAML under `configs/printers`, `configs/chem`, and `configs/safety` is intentionally an empty mapping. Those schemas belong to later tasks. Agents must not edit the safety or reagent files.
